# Results

This directory contains reference output tables generated by the validated
analysis scripts in `scripts/analysis/`.

The files in `results/tables/` are provided to facilitate verification of the
reproducibility workflow. They can be regenerated by running the corresponding
analysis scripts described in `RUN_ORDER.md`.

These tables are derived analytical outputs and do not contain redistributed
third-party raw data.

## Main groups of outputs

- Lag-correlation and persistence diagnostics
- Primary conditional-model results
- Model-specification and air-temperature-window sensitivity analyses
- Time-blocked cross-validation and persistence benchmarks
- Soil-moisture sensitivity
- Seasonal sensitivity
- ERA5-Land and FLDAS cross-product comparison
- Terrain sensitivity
- Lake-cover sensitivity

Some files contain bootstrap or fold-level results, whereas others contain
summary statistics used in the manuscript and supplementary material.
